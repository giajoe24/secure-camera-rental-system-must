やるべきこと(11/18 MTG のあと)
==========================

■ 11/18 の MTG で決まった MUST を反映した
    - 返却は登録している人なら誰でもできる(借りた人と返した人を別々に記録)
    - 返却にも確認画面(「返す」を押してから解錠)
    - 記録は追記だけ(解錠 → 完了 / 取り消し の行を足していく。上書き・削除しない)
    - 扉が閉まって施錠したのを確かめてから「完了」
      30 秒以内に扉が開かれなければ取り消し、開いたまま 60 秒で警告(点滅なし)
    - 画面を 7インチ(800×480)に合わせて作り直した。ちらつきの原因も直した
    - このリポジトリは MUST だけ。追加機能(WANT)は secure-camera-rental-system の方
    - 記録は exports/rental_log.xlsx に自動で保存(貸出・返却が終わるたびに更新)
      ラズパイの中にあるので、見られるのはラズパイを触れる管理者だけ
    - 利用者の登録は python register.py(社員証をかざして、社員番号と氏名を入れる)

■ 資料(docs/)
    MUST一覧.txt  MUST とできた/できていない
    仕組み.txt    ファイルの役割、データの流れ、DB のテーブル
    flowchart.png 貸出・返却の流れ

■ 実機でやること
[ ] ラズパイに *.py を全部送り直す
    data/ は送らない。今回 DB の作りが変わったので、古い data/ は消してから起動する
    (前の記録は残らない。残したければ先に別の場所へコピーしておく)
    pip install openpyxl
[ ] 7インチモニターで全画面を確かめる(文字・ボタンの見切れ、押しやすさ)
[ ] 利用者を登録する: main.py を止めて python register.py(USB キーボードを使う)
[ ] 貸出・返却を通しで試す
    扉を開けて閉めたら完了になるか
    扉を開けずに 30 秒待つと取り消しになるか
    開けたままにすると警告が出るか
[ ] 待ち時間(config.py の CARD_WAIT_SECONDS など)を実機で決める(10〜30 秒)

■ 回路
[ ] MOSFET の足をはんだ付けして、ブレッドボードの接触不良をなくす
[ ] 太く短い線にする(5V → LE-53 → ドレイン、ソース → GND)
[ ] 回路図(circuit/lock_driver.asc)に GPIO23 のスイッチ(外付け 10kΩ プルアップ)を書き足す
[ ] 回路図をアドバイザーに見てもらう
